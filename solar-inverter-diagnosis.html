Solar cell ดับไปเฉยๆ — production = 0 แต่ inverter ยังติดอยู่ แอพขึ้น alert ว่า UVP (Under Voltage Protection) กับ UFP (Under Frequency Protection) สับสะพานไฟ AC, DC ปิดเปิดเครื่องก็ไม่หาย กำลังจะเรียกช่างมาดู แต่แล้วนึกขึ้นได้ว่า OpenClaw มันเห็น sensor ทุกตัวที่ inverter ส่งออกมา...

--- ## การวินิจฉัยผ่าน Home Assistant Sensor Data **ข้อมูลที่ได้จาก Home Assistant:

Sensorค่าที่อ่านได้ค่าปกติสถานะ
L1 Voltage4.1V~220V❌ ใกล้ศูนย์
L2 Voltage3.2V~220V❌ ใกล้ศูนย์
L3 Voltage229V~220V✅ ปกติ
PV1/PV2 Voltage736V~700V✅ ปกติ
Grid Frequency0 Hz50 Hz❌ อ่านไม่ได้
Power Production0W—❌ Inverter ไม่ทำงาน

Fault code: ID10 — PV Input Current Unbalanced

--- ### สิ่งที่น่าสนใจ: Phantom Voltage บน L1 และ L2 ถ้าสายไฟขาดสนิทเป็น open circuit ควรจะอ่านได้ 0V แต่กลับได้ ~4V บน L1 และ ~3V บน L2 — นี่คือ phantom voltage ที่เกิดจาก capacitive coupling จากสาย L3 ที่ยังมีไฟ มาพันกันอยู่ในท่อเดียวกัน ทำให้เหนี่ยวนำไฟฟ้ามาที่สายที่ขาด

--- ## การตรวจสอบที่ตู้กระจายไฟ
  • วัดที่เบรกเกอร์ของ inverter — ทั้ง 3 เฟส ขึ้น 220V ครบ ✅
  • แต่วัดที่ขั้ว AC ของ inverter เอง — L1 กับ L2 ได้แค่ 4V ❌

สรุป: ไฟมาถึงเบรกเกอร์ปกติ แต่หายไปก่อนถึง inverter — สาเหตุน่าจะอยู่ที่สายไฟหรืออุปกรณ์ป้องกันระหว่างเบรกเกอร์กับ inverter

--- ## เปิดกล่องต่อสายดู เปิด connection box ที่อยู่ระหว่างเบรกเกอร์กับ inverter → เจอ fuse ขาด 2 ตัว สำหรับ L1 และ L2 เป็นช่องที่เห็นชัดเจนว่าขาดสนิท (burnt out)

Fuse ที่หาย: SHINOHARA RT14-20, 20A, 500V~, gG (general-purpose)

🔧 หมายเหตุ: SHINOHARA เป็นของญี่ปุ่นดีมาก มี interrupting rating 100kA ซึ่งสูงมากสำหรับ fuse ขนาด ø10×38mm
--- ## บทสรุป
  1. Symptom: UVP/UFP fault → production = 0
  2. Data: L1=4.1V, L2=3.2V, L3=229V → สรุป L1+L2 หาย
  3. Hypothesis: ไฟ AC ไม่เข้าสองเฟส
  4. Action: ตรวจสอบที่ตู้กระจายไฟ → เจอ fuse ขาด
  5. Result: เปลี่ยน fuse → inverter กลับมาทำงานปกติ
